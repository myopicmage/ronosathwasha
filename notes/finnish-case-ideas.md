# Mine Finnish cases for ideas

Status: research direction, not canon. No forms are decided here.

Finnish is a strong source of semantic questions for Rono because its cases are
small compositional systems rather than a flat inventory of unrelated endings.
The goal is to mine the pressures those systems solve, then derive Rono-shaped
answers from Rono's existing machinery.

## Governing preference: make the relation explicit

Rono should err on the side of explicit relations. Avoid a system where a
speaker must choose among broad locative markers primarily from the predicate
or context, as Kevin experiences with Korean `에` and `에서`.

Static location, event location, destination, and source are different
relations. If Rono needs them, the morphology should expose the distinction
rather than make a speaker recover it from convention. This is a design
preference, not yet a decision that every relation needs its own morpheme.

Rono currently distinguishes:

```text
LOC.AT    -shi / -shu
LOC.IN    -thi / -thu
LOC.NEAR  -mi  / -mu
LOC.TO    -ði  / -ðu
```

The audit should ask which relations are genuinely missing and which current
ones are carrying more than one semantic job.

## High-interest seams

### Source relations

Finnish distinguishes source from destination and further distinguishes source
from an internal location from source at an external location. Rono has an
explicit toward relation but no corresponding declared source relation.

Questions to test:

- Does Rono need one general "from" relation or separate "out of" and "from at" relations?
- Is departure from proximity distinct from departure from containment?
- Can a source relation extend to causes without becoming vague?

### State, role, and becoming

Finnish essive and translative morphology distinguishes being or acting as
something from becoming something. This is directly relevant to Rono's existing
pressure around classification, temporary role, current identity, and change.

Questions to test:

- Does Rono need to distinguish identity from temporary capacity?
- Is becoming a nominal relation, an event transition, or a derivation of the
  existing copularizer?
- Can the distinction clarify forms such as the fire-elemental house without
  manufacturing a general change system prematurely?

### Affectedness and completion

Finnish object marking can distinguish an open, incomplete, or unbounded event
from one that affects a bounded object completely. Rono should investigate the
semantic distinction without assuming that case is where it belongs.

Questions to test:

- Is affectedness a property of the object, the event, or their relationship?
- How would it interact with Rono's continuous aspect and negation?
- Should a completed transition entail a resulting world state that an ongoing
  event does not?

## Deliberately unresolved: possession as location

Finnish can model possession as existence located at a possessor. Kevin is
currently unconvinced that Rono should follow it. Rono already has `ti`, "have,"
and that ordinary predicate should not be displaced without a concrete semantic
gain.

Keep possession-as-location available as comparative evidence, not as a feature
proposal. The useful result may be confirmation that Rono's lexical possession
verb is the better fit.

## Research test

For each candidate:

1. State the semantic contrast without Finnish terminology.
2. Find a Rono situation where the contrast changes what follows.
3. Check whether existing morphology already represents it.
4. Add machinery only if the contrast remains both useful and otherwise
   inexpressible.

Mine the distinction, not the case ending.
